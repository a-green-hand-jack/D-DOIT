D-DOIT:
Training-free Adaptation of Discrete Diffusion

via Doob’s h-Transform

Jieke WuQijie ZhuWeimin Wu Zeqi YeMinshuo ChenHan Liu

Northwestern University · King Abdullah University of Science and Technology

D-DOIT adapts a frozen masked discrete diffusion model to generic black-box sequence rewards by reweighting categorical token-reveal transitions with a discrete Doob h-transform.

The idea

Adapt the sampling law.
Keep the backbone fixed.

01

Training-free

No parameter updates or reward backpropagation are needed during adaptation.

02

Black-box rewards

Use reward values directly, even when the evaluator is non-differentiable.

03

Kernel-level guidance

Reweight the categorical reveal transitions where masked diffusion makes its decisions.

Method

A discrete Doob transform in three moves.

Starting from a frozen masked diffusion model, D-DOIT turns a reward function into an inference-time change of measure.

01

Propose

Draw a small set of candidate next states from the frozen reverse transition.

02

Estimate value

Complete each candidate with one prediction-head pass and query the black-box reward.

03

Reweight

Sample the next state according to the estimated Doob weights, with optional late-stage best-of-K refinement.

Reward-tilted target πβ(x) ∝ pθ(x)eR(x)/β the reference law that the practical sampler approximates
Executable sampler

From the exact transform to a finite-candidate update.

The reported implementation uses a prediction-head completion for each candidate, then samples the next state with the estimated Doob weights. The optional split is only used to hedge irreversible reveals late in the chain.

Algorithm 1D-DOIT with optional best-of-K refinement
Input: frozen Pθ, reward R, batch B, steps L,
       guidance window [lend, l*], split index ssplit, width K,
       guided-step parameters (M, ω, β, τ, γ)

Initialize B all-mask trajectories at time tL
for s = 0, 1, …, L − 1:
    if s = ssplit and K > 1:
        duplicate each active trajectory into K copies
    l ← L − s
    if lend ≤ l ≤ l*:
        x̄tl−1 ← DoobGuidedStep(x̄tl; M, ω, β, τ, γ)
    else:
        x̄tl−1 ∼ Pθ(· | x̄tl)
return the highest-reward clean copy in each group (or all clean sequences when K = 1)

The split and terminal ranking are optional. Setting K = 1 disables best-of-K refinement and recovers the core D-DOIT branch.

Algorithm 2DoobGuidedStep
1. Compute the prediction head μθj(· | x̄tl, tl) once for all positions.
2. Form μθ,τj(v) ∝ μθj(v)1/τ and draw M candidate states ȳ(m).
3. For each candidate m, draw a clean completion x̂0(m) from the tempered prediction head.
4. Set ĥ(m) ← exp(R(x̂0(m)) / β).
5. Sample m* ∝ (ĥ(m))ω and return x̄tl−1 = ȳ(m*).

One guided step costs one shared proposal pass, M prediction-head completions, and M reward evaluations. The reported operating points omit the proposal-ratio correction; this is the practical estimator rather than an exact-target guarantee.

Takeaways

The model stays intact while the sampler adapts.

D-DOIT is designed for settings where reward evaluation is available but training a task-specific model is undesirable. Its practical sampler uses a prediction-head h-estimator and finite-candidate selection.

The paper reports reward gains together with naturalness, structural, and compute diagnostics. These measurements describe task-specific trade-offs rather than a claim of universal dominance.
